# 🛒 Сатып алуларды жоспарлаушысы (Shopping List Planner)

> **Сатып алуларды жоспарлаушысы** — бұл пайдаланушыларға өз бюджетін тиімді басқаруға, сатып алу тізімдерін құруға және шығындарды сараптауға арналған заманауи веб-қосымша (SaaS). 
> 
> Жоба толығымен қазақ тілінде әзірленген және **Firebase (Auth + Cloud Firestore)** бұлтты технологиялары арқылы кез келген құрылғыдан (смартфон, планшет, ПК) деректерді нақты уақыт режимінде синхрондауды қолдайды.

---

## 🌟 Негізгі мүмкіндіктері (Key Features)

* **🔐 Ғаламдық бұлтты авторизация:** Электрондық пошта (Email) және құпия сөз арқылы тіркелу және кіру. Деректер бұлтта сенімді сақталады.
* **📱 Мобильді кросс-платформалық сипат:** Тіркелген аккаунтқа кез келген құрылғыдан кіріп, өз тізімдеріңіз бен бюджетіңізді қайта жүктеу мүмкіндігі.
* **💰 Бюджетті жоспарлау және бақылау:** Жалпы бюджетті белгілеу, жұмсалған қаражатты және қалған балансты автоматты түрде есептеу.
* **🗂 Категориялар мен сүзгілер:** Тауарларды санаттар бойынша бөлу, «сатып алынды» статусын қою және жылдам сүзгілеу.
* **📊 Аналитика мен статистика:** Шығындардың пайызын және статистикасын визуализациялау.
* **🎨 Заманауи UX/UI:** Light Minimal стильдегі адаптивті интерфейс.

---

## ✨ Жаңартылған интерфейс (v2)

Қолданбаның дизайны ақ / қара / қызыл минимализм стиліне көшірілді (қызыл түс тек негізгі әрекеттер, белсенді таб, жою және бюджет ескертулері үшін).

* **Бюджет карточкалары:** Жалпы бюджет, Жоспарланған сома, Орындалған сома, Қалдық — нақты уақытта есептеледі.
* **Бюджет ескертуі:** жоспар бюджеттен асса, «Қалдық» карточкасы қызыл болып, «Бюджеттен асу!» белгісі шығады.
* **Чекбокс:** тауарды «Сатып алынды» деп белгілегенде атауы сызылып, «Орындалған сома» мен «Қалдық» бірден жаңарады.
* **Құралдар панелі:** нақты уақыттағы іздеу, категория және күй сүзгісі, баға / маңыздылық / күні бойынша сұрыптау.
* **Аналитика:** категориялар бойынша түсті прогресс-барлар (пайызбен), орындалу барысы, маңыздылық бойынша бөлініс, калькулятор.
* **Есеп жүктеу:** Excel (.xlsx, екі парақ: тізім және қорытынды) және PDF (басып шығару терезесі арқылы).
* **«+ Жаңа тауар қосу»:** модаль терезе; міндетті емес жеңілдік (%) және валюта (₸, $, €, ₽) өрістері, қорытынды соманың тірі калькуляторы.

> Валюта курстары `script.js` ішіндегі `CURRENCIES` тізімінде шамамен берілген — қажет болса жаңартыңыз.

## 🛠 Технологиялық стек (Tech Stack)

* **Frontend:** HTML5, CSS3 (Flexbox/Grid, CSS Variables, Animations), JavaScript (ES6+).
* **Backend-as-a-Service (BaaS):** Firebase Authentication.
* **Database:** Firebase Cloud Firestore (NoSQL cloud database).
* **Security:** Cloud Firestore Security Rules (пайдаланушы деректерін оқшаулау).
* **Deployment:** GitHub Pages / Netlify.

## 🔒 Қауіпсіздік ережелері (Firestore Security Rules)

Әр пайдаланушының жеке деректерін қорғау үшін Firestore дерекқор деңгейінде арнайы қауіпсіздік ережелері енгізілген:

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
      match /{document=**} {
        allow read, write: if request.auth != null && request.auth.uid == userId;
      }
    }
  }
}
